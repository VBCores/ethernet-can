## Где лежат настройки

| Файл | Где хранится | Назначение |
| --- | --- | --- |
| `ethernetcan.json` | Linux: `/opt/voltbro/ethernet-can/` | IP компьютера, адрес платы, интерфейсы SocketCAN; необязательная секция `fdcan` |
| `config.json` | Корень SD, если используется | Сетевые настройки платы и блокировки runtime-полей |
| Запись во Flash H7 | Внутри платы | Последняя сохранённая конфигурация CAN; отдельного `runtime.json` нет |

С `fdcan` клиент задаёт скорости и период, а после нескольких неуспешных проверок восстанавливает свою конфигурацию. Без `fdcan` он ждёт конфигурацию с платы; её IP назначения и список шин должны совпадать с host JSON. Поэтому изменения панели может перезаписать клиент, если в host JSON есть `fdcan`.

`network.host_ip` в host JSON — адрес **компьютера**. `network.device_ip` — адрес или имя **платы**. Карта `host_interface_map` включает нужные шины; отсутствующие шины выключаются при настройке с компьютера. Несколько плат обслуживает один процесс, по одному JSON на плату.

`fdcan.period_ns` — период агрегации UDP в наносекундах: `10000000` = 10 мс, `0` = отправка сразу. Это не частота генерации CAN-сообщений. `nominal_kbit` и `data_kbit` задают скорости; `data_kbit: 0` означает classic CAN. Формат выбирается для всей шины. Поле wire-протокола содержит номер шины и CAN ID, но не отдельный бит classic/FD. В classic mode payload ограничен 8 байтами; CAN FD использует длины 0..8, 12, 16, 20, 24, 32, 48, 64.

## SD и загрузка

Без SD включены DHCP и имя `ethernetcan.local`; MAC выводится из UID H7. На SD поддерживаются `network.hostname`, `dhcp`, `device_ip`, `netmask`, `gateway`, `host_ip`, `mac_address`, `wake_on_lan_mac`/`wol_mac`. Для статического IP задавайте `dhcp:false` вместе с `device_ip`. Пользовательский `config.json` прошивка не перезаписывает; размер файла должен быть меньше 2048 байт.

Runtime-поля `data_plane.host_ip`, `frames_integration_period_ns` и явно заданные поля `buses` блокируются SD. При загрузке прошивка проверяет запись Flash и совместимость с SD; при конфликте пытается собрать полную конфигурацию из SD и сохранить её. Без полной конфигурации сеть и панель доступны, но CAN ждёт настройки. INI и `runtime.json` больше не используются.

Проверки подключения и таблица проблем: [Troubleshooting](../README_ru.md#troubleshooting--если-что-то-не-работает).
